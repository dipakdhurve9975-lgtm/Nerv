Why it's cheap.

Same office, a fraction of the tokens.

Most agents burn tokens by throwing everything at one expensive model, sequentially. NERV doesn't.

🔌 Model routing.

Small model for easy lookups, bigger model for planning. Cuts cost 60–80% on most agent steps.

💾 Prompt caching.

Shared system instructions and context are cached, not re-sent on every worker call.

🧠 Code over AI calls.

Deterministic steps run as plain code. The AI is only called when a real judgment call is needed.

⚡ Parallel workers.

Independent agents run at the same time instead of waiting on each other in one long chain.

📁 Shared memory.

A lightweight shared store means agents stop re-explaining context to each other.

Questions people actually ask.

Isn't this just a chatbot with extra steps?

No — a chatbot answers once and stops. NERV loops: perceive, plan, act, observe, re-plan, escalate, repeat, until the goal is actually done, with real tool calls happening in between.

What happens when a step fails mid-run?

The Manager Agent notices, decides whether to skip, retry, or flag it for you, and continues with the rest of the plan instead of stopping the whole run.

Who approves the risky stuff?

You do. In manual mode every action waits for a thumbs up; in auto mode only high-stakes actions — money, external emails, deleting data — pause for approval, on the web or on Telegram.

Which tools can it actually use?

Five today: reading spreadsheets, sending email, querying a database, requesting approval, and running shell commands inside a sandboxed container. Nothing runs outside that box.

Is my data private?

Local first. Messages between agents are sealed per device with X25519 sealed boxes and XChaCha20, signed with Ed25519. Keys never leave your machines.
